# ---------------------------------------------------------------------------
# AI and answer-engine crawlers, listed explicitly.
#
# The wildcard above already permits these, but naming them is deliberate:
# several operators publish per-agent rules, and an explicit Allow removes any
# ambiguity about whether Sellapage content may be read and cited. These are the
# crawlers behind ChatGPT, Claude, Perplexity, Gemini and Common Crawl, so this
# is what decides whether an assistant can answer "what is Sellapage".
#
# Note they mostly do NOT execute JavaScript, which is why the public routes are
# prerendered to static HTML at build time (scripts/prerender-seo.mjs). Allowing
# them here is only half the job; the other half is giving them something to read.
# ---------------------------------------------------------------------------
